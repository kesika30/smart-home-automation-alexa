# Smart Home Automation System (Alexa + IoT)

An IoT-based home automation system that lets you control home appliances both **manually** (physical switches) and **remotely via Amazon Alexa**, using an ESP32/ESP8266 board connected to Arduino IoT Cloud.

## Overview

This project integrates:
- **Relay-based appliance control** — two relays switch connected devices (lights, fans, etc.) ON/OFF.
- **Manual override switches** — physical push-button switches for local control, independent of WiFi.
- **Arduino IoT Cloud + Alexa integration** — appliances can be toggled remotely through the Arduino IoT Cloud dashboard or voice commands via Alexa.
- **WiFi status indicator** — an onboard LED shows whether the device is connected to the cloud.

## Hardware Used

| Component            | Purpose                              |
|-----------------------|---------------------------------------|
| ESP32 / ESP8266        | Main microcontroller, WiFi connectivity |
| 2-Channel Relay Module | Switches connected appliances          |
| Push Button Switches   | Manual local control                   |
| LED                    | WiFi connection status indicator       |
| Arduino IoT Cloud       | Remote control + Alexa integration    |

## How It Works

1. On boot, the device connects to WiFi and Arduino IoT Cloud using credentials stored in `arduino_secrets.h`.
2. Two relays (`RelayPin1`, `RelayPin2`) control connected appliances.
3. Devices can be toggled two ways:
   - **Manually** — pressing the physical switch pins toggles the relay directly.
   - **Remotely** — toggling `switch1` / `switch2` on the Arduino IoT Cloud dashboard (or via Alexa, once linked) triggers `onSwitch1Change()` / `onSwitch2Change()`.
4. An onboard LED (`wifiLed`) turns on when WiFi is disconnected and off when connected, giving a quick visual status check.

## Setup Instructions

1. Install the **Arduino IoT Cloud** library and set up a Thing on [Arduino Cloud](https://cloud.arduino.cc/).
2. Add two `CloudSwitch` variables named `switch1` and `switch2` to your Thing.
3. Rename `arduino_secrets.h.example` to `arduino_secrets.h` and fill in your own:
   ```cpp
   #define SECRET_SSID "your_wifi_name"
   #define SECRET_PASS "your_wifi_password"
   #define SECRET_DEVICE_KEY "your_device_key"
   ```
4. Update `THING_ID` and `DEVICE_LOGIN_NAME` in `thingProperties.h` with your own Thing ID and Device ID from Arduino IoT Cloud.
5. Upload the sketch to your ESP32/ESP8266 board.
6. Link your Arduino Cloud Thing to Alexa via the **Arduino IoT Cloud skill** in the Alexa app to enable voice control.

## Note on Security

`arduino_secrets.h` contains WiFi and device credentials and is **excluded via `.gitignore`** — only the `.example` template is committed. Anyone using this project should create their own `arduino_secrets.h` locally and never commit real credentials.
